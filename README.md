# dotSearch 搜索优化脚本

全面增强Web搜索体验

# 主要功能

- 基于UserScript 各种浏览器全面兼容<sup>1</sup>
- 去广告去AI 直达搜索结果
- 重制大部分页面 增强视觉体验
- 支持隐藏或标记特定网站结果
- 增强深色模式支持
- 兼容第三方拼页插件<sup>2</sup>
- 保留源搜索引擎大部分附加功能<sup>3</sup>

# 特别提醒
